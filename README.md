# Customizable Dashboard Widgets

A modern, responsive dashboard application equipped with customizable widgets, allowing users to manage tasks, view employee data, and configure settings with ease.

## Features

- **Interactive Dashboard**: Drag-and-drop widgets to personalize your workspace.
- **Task Management**: Track and manage project tasks efficiently.
- **Employee Directory**: View and manage employee information.
- **Settings**: Configure application preferences.
- **Data Visualization**: insightful charts and metrics.

## Getting Started

Follow these steps to set up and run the project on your local machine.

### Prerequisites

- Node.js installed on your system.

### Installation

1. Navigate to the client directory:
   ```bash
   cd client
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit the URL shown in the terminal (usually `http://localhost:5173`).

## Technologies Used

- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Routing**: Wouter
- **Charts**: Recharts
- **Layout**: React Grid Layout
